# Guia de Uso — PROTEGER-NR1 EPT

Manual de uso do sistema, escrito para quem **usa** o PROTEGER-NR1 EPT
no dia a dia — Administrador, Consultor e quem responde o questionário —
não para quem desenvolve. Se você procura documentação técnica
(arquitetura, modelo de dados, API), veja `docs/` (pasta acima desta).

Este conteúdo foi escrito para virar a **Wiki do projeto no GitHub**:
cada arquivo aqui corresponde a uma página da Wiki, e os diagramas usam
[Mermaid](https://mermaid.js.org/), que o GitHub renderiza nativamente
tanto em arquivos do repositório quanto na Wiki.

## Sobre os prints de tela

Os textos abaixo têm marcações no formato:

> Espaço para print de tela: **Nome da tela**

Esses são os pontos onde uma captura de tela real deve entrar quando o
conteúdo for publicado na Wiki — procure por "Espaço para print" em
qualquer arquivo desta pasta para encontrar todos de uma vez.
